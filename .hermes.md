# .hermes.md — aturan khusus Hermes (akunting)

1. Lokasi fisik repo: /home/aiagent/Projects/akunting. Path lama /home/aiagent/hermes/projects/akunting tetap sah melalui symlink, termasuk referensi absolut di worktree lama.
2. Worktree task kanban: .worktrees/<task-id> di dalam repo, dibuat daemon kanban sebagai workspace kind worktree. Jangan dihapus di luar siklus hidup task-nya.
3. Go toolchain di ~/tools/go/bin (di luar PATH default); lihat AGENTS.md untuk urutan export PATH.
4. Smoketest `go run ./cmd/smoketest` mandiri dan aman (DB smoke dibuat lalu di-drop sendiri).
5. Layanan live: `systemctl --user status accounting.service`; binary live /home/aiagent/Archives/builds/accountingd via symlink /home/aiagent/hermes/projects/bin/accountingd.
6. Dilarang menyentuh ~/.hermes milik profil lain dan dilarang sudo.
